# 阶段 2 验收 · 照着点步骤（产品经理版）

> 目标：验证「粘贴小红书链接 → 16 景点 → 人工确认 → 百度地图动线 → 跳转 App / 分享 / 长图」。

## 前置
让 AI 启动后端（或按 README 启动），然后浏览器打开 **http://127.0.0.1:8000/**

## 步骤
1. 页面标题是「TripFlow 旅行全流程助手」。
2. 点「演示链接」，输入框自动填入重庆攻略链接；点「**生成**」。
3. 等约 10~30 秒，出现「**地点确认**」卡片：应显示 **16 个地点**，Day1/Day2 各 8 个，顺序与笔记一致（解放碑→…→江滩公园；鹅岭公园→…→塔坪）。
4. 随便改一个地点名、或勾选一个「跳过」，验证列表可编辑（确认前不会生成动线）。
5. 点「**生成动线**」，等几秒出现「**动线结果**」：逐天地图 + 每段「交通方式 + 耗时」。
6. 点「**跳转百度地图 App**」→ 手机/电脑唤起百度地图导航。
7. 点「**复制分享链接**」→ 复制 `/share/{行程id}`，新开无痕窗口打开，确认能看到同一份动线、且只读。
8. 点「**导出长图**」→ 自动下载高清长图（封面 + 逐天动线 + 地点卡片 + 耗时）。

## 对照验收标准（AC-1.x）
- 16 景点召回 100%（≥80% ✅）
- POI 定位 16/16（≥70% ✅）
- 确认前不生成动线（步骤 4 验证 ✅）
- 动线渲染 + 跳转 App（步骤 5/6 ✅）
