# 阶段 3 验收 · 照着点步骤（产品经理版）

> 单端口交付，浏览器打开 **http://127.0.0.1:8000/**

1. 首页显示「把攻略变成一张可走的动线」+ 输入框。
2. 点「**试试这篇重庆攻略 →**」，等 20~30 秒出现地点清单（Day1/Day2 各 8 个，共 16 个）。
3. 试试编辑：改一个地点名、给它**换 POI**（下拉选候选）、调整**天**、勾选**跳过**一个点。
4. 点「**确认并生成动线**」，等几秒出现「动线结果」：每天一张地图 + 每段「交通方式 · 耗时」。
5. 点「**跳转百度地图 App**」→ 唤起百度地图导航。
6. 点「**分享**」→ 复制链接，新开无痕窗口打开 `/share/{行程id}`，确认只读、能看到同一份动线。
7. 点「**导出长图**」→ 自动打开高清长图 PNG。
8. 刷新页面（URL 带 `?trip=行程id`）→ 能恢复到同一份行程。

## 当前已知说明
- 地图目前是**静态图**（真实动线渲染）；等你提供**浏览器端 AK** 后自动升级为可拖动缩放的 JSAPI GL 交互地图（填 `frontend/src/lib/config.ts` 的 `BAIDU_JSAPI_AK`，再 `npm run build`）。
- 视觉为功能优先版本，审美打磨后续再迭代。
