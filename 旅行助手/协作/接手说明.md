# 途书旅记 · 朋友接手说明

## 从哪里开始

项目目录：`项目开发必备文件/旅行助手/`。先看该目录 README、`开发文档/项目状态.md` 和 `开发文档/第3阶段前端开发文档.md`。

这次上传为当前最新源码和文档快照，不携带此前 Git 历史。仓库中的历史截图仅是当时版本的证据，不代表最新页面已完成验收。

## 本机配置与启动

1. 在旅行助手目录，把 `.env.example` 复制为 `.env`，自行配置后端服务端地图 AK 和 DeepSeek Key。
2. 把 `frontend/.env.example` 复制为 `frontend/.env.local`，自行填写浏览器端地图 AK（与服务端 AK 分开）。留空时使用后端静态地图兜底。不要把个人密钥发在聊天或提交到 Git。
3. 进入 `frontend` 执行 `npm ci` 和 `npm run build`。
4. 进入 `backend`：用 Python 3.12 创建 `.venv`，安装 `requirements.txt`，安装 Playwright Chromium（长图导出需要）。具体命令见 README。
5. 启动 FastAPI 后打开 `http://127.0.0.1:8000/`。本机数据库不会随仓库共享，旧文档里带行程 ID 的链接在新机器上不能直接恢复。
6. 修改前端时，在 `frontend` 执行 `npm run dev`，打开 5173；API 代理到 8000。完成后执行构建，8000 才显示新构建。

## 协作方式

- 每人使用自己的分支，按页面或文件分工；修改后通过 Pull Request 合并。
- 首页/工作台：`frontend/src/components/JourneyWorkspace.tsx`。
- 结果区：`frontend/src/components/RouteView.tsx`。
- 地图：`frontend/src/components/MapView.tsx`。
- 公共样式：`frontend/src/index.css`，避免多人同时修改同一段。
- 后端接口前缀 `/api/v1`；文档、实现有历史差异，以真实路由为准。
