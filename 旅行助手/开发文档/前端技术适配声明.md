## 3. 技术选择
- 框架：**Vite + React 19 + TypeScript strict**（偏离 Next.js 默认，见 §6）
- 样式：Tailwind CSS + 语义设计变量；图标 Lucide
- 数据请求：集中 API 层（`/api/v1`，统一错误处理）
- 状态：React 组件状态 + 任务轮询；不引入状态库（单页、无远距离跨组件共享）
- 地图：百度地图 **JSAPI GL**（需浏览器端 AK，referer 白名单 `localhost:8000`）
- 测试：Vitest + React Testing Library（单元）+ Playwright（核心闭环 E2E）；ESLint + 类型检查 + 生产构建为交付门槛
- 部署形态：Vite 构建产物由 FastAPI 挂载，**单端口 8000 单源**（无 CORS、分享链接一致）

## 4. Agent 状态
- 后端状态 → 前端状态映射：`trip.status`（created/parsing/awaiting_confirm/routing/done/failed）+ `task.status`（pending/running/done/failed）
- 等待确认：`awaiting_confirm` → 展示可编辑地点清单；确认后 `POST /route`
- 取消/重试/恢复：按 `trip_id` + `task_id` 轮询；页面刷新后凭 URL 中 `trip` 参数恢复（行程 ID 即恢复入口）；失败可重新提交
- 加载/空/失败/等待确认/断线恢复 六态均需可区分展示

## 5. 页面与产物
- 核心页面（单页三区块）：① 输入（粘贴链接）② 地点确认（清单 + 改名 + 换 POI + 分天 + 跳过）③ 动线结果（JSAPI GL 地图 + 分段耗时 + 跳转 App + 分享 + 长图导出）
- 核心闭环：粘贴 → 生成 → 确认 → 地图 → 分享/导出
- 产物预览：内嵌交互地图、长图 PNG 下载
- 响应式目标：桌面 1280 / 移动 375

## 6. 偏离本手册的地方
- 偏离：不用 Next.js，改用 Vite SPA。
- 原因：本产品是单页单流程、无多页面/SEO/SSR 需求，命中手册 §5.1「产品只需要一个很小的嵌入式页面」的偏离条件；地图交互是纯客户端能力，SPA 更轻、本机跑更简单。
- 影响：缺 SSR/路由，本项目用不上；未来扩展多页面时再评估。
